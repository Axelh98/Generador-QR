# Generador de QR

Página web para crear códigos QR de links, texto, WiFi, email y teléfono.

- Vista previa en vivo
- Descarga en PNG o SVG, o copia la imagen
- Colores, tamaño, margen y nivel de corrección de errores
- Logo opcional en el centro

Todo funciona en el navegador; ningún dato se envía a un servidor.

Usa la librería [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT), incluida en `qrcode.js`.
